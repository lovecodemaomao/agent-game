# Proposal: sim-platform-and-agents

## Why

《未来战争》对抗赛只提供比赛环境的接口文档与报文样例，本地没有判题器与 LLM API，无法迭代策略。需要一套本地模拟对战平台（扮演判题器与中立系统）与两个可对战的 agent（我方智能 agent + 固定策略对手 agent），通过可视化复盘每一回合的双方动作来驱动策略进化。同时，赛制规定异常响应累计 5 次即淘汰，因此所有出站指令必须经过确定性的严格格式校验，从工程上杜绝"因参数不规范导致行动失败"。

## What Changes

- 新建 Python 项目，包含四个子系统：
  1. **模拟对战平台（判题器）**：复刻任务书规则的战斗引擎（地图 41×32、昼夜 130 回合/天、8 向移动与碰撞、采集/建造/贩卖/购买、武器攻击结算、机器人波次、积分与胜负判定），通过 HTTP 以《接口文档》规定的 request/response 报文与双方 agent 交互，并实现 LLM 代理（转发 `prompt` 字段、回填 `llmResp`、每日 3 次配额与任务期豁免）、沙盒执行（`executeCmd`，15 秒超时、mock 任务 API）与异常计数（5 次淘汰）。
  2. **我方 agent（competitor）**：HTTP server 骨架 + 回合编排器 + WorldModel + **OpponentModel 组件**（每回合从全局信息通道 diff 出对手全部确定性动作并滚动更新）+ 确定性策略引擎（教义×旋钮参数化，日常调度零 LLM）+ 每日 3 次 LLM 思考预算（日界分析对手动向并热替换当日教义参数）+ 任务/宝藏求解代理（LLM 与沙盒双通道流水线，SOP 沉淀）。
  3. **对手 agent（baseline）**：与判题器同协议接入，10 天固定一种策略不做每日 LLM 调度；仅任务与自进化任务期间使用 LLM 辅助完成。
  4. **前端可视化**：逐回合展示双方全部动作、地图单位状态、资源/积分/日志，支持回放与调速。
- LLM 统一使用 deepseek-v4.1-flash，划分为 **3 个互不互通的独立调用上下文**：我方 agent、中立新闻系统、对手 agent（后两者由模拟平台侧持有）。
- 双方 agent 共用一层**确定性出站指令校验器**：任何 `roleCommandMap`/`prompt`/`executeCmd` 输出，必须通过 schema 严格校验（字段完整性、动作码合法性、参数类型与取值域、ID 归属）后才允许提交到模拟平台；校验失败在本地兜底修正，不允许非法报文出站。
- 新增中立新闻系统：独立 LLM 上下文按天生成官方消息（矿产价格波动事件）与民间传闻（宝藏谜题线索链）。

## Capabilities

### New Capabilities

- `sim-battle-engine`: 战斗引擎——忠实复刻任务书的地图/昼夜/移动碰撞/采集建造/经济/武器攻击结算/机器人波次/积分与胜负规则，对文档未定义之处采用可配置参数化假设。
- `sim-judge-loop`: 判题循环——以《接口文档》报文格式驱动双方 agent 回合调度，充当 LLM 代理（每日 3 次配额、任务期豁免）、沙盒执行器与异常计数器，判定比赛结束与胜负。
- `sim-news-system`: 中立新闻系统——独立 LLM 上下文生成每日官方消息与民间传闻谜题，并计算其对矿价/采集/宝藏的确定性影响。
- `sim-frontend`: 对战可视化前端——逐回合渲染双方动作、地图与单位状态、资源积分曲线与事件日志，支持回放。
- `agent-framework`: agent 公共骨架——HTTP server、回合编排（先返回后计算）、出站严格格式校验器、LLM prompt 异步通道管理、任务求解代理（双方 agent 共用）。
- `agent-competitor`: 我方 agent——OpponentModel（每回合收集对手确定性动作）、教义×旋钮策略引擎、每日 3 次 LLM 预算下的日界策略分析。
- `agent-opponent-baseline`: 对手 agent——10 天固定策略（可配置预设卡），仅任务期使用 LLM。

### Modified Capabilities

（无——全新项目，尚无既有规格。）

## Impact

- **新增代码**：`sim/`（引擎+判题循环+新闻+前端服务）、`agents/`（公共骨架+我方+对手）、`config/`（地图/波次/新闻参数与教义预设卡）。
- **外部依赖**：deepseek API（密钥读取自仓库内 `deepseek-key.md`，密钥本身不进入代码与规格文档）；Python Web 框架与轻量前端（无重型构建链）。
- **不影响**：`docs/` 比赛材料（只读参照物，报文格式以其为唯一权威）。
- **关键约束**：本变更只搭建系统与固定基线对战；批量参数扫描、自进化策略养库（教练 LLM、k-NN 推荐表）不在本次范围，作为后续变更。
